Funcionalidades completas estilo Trello
---------------------------------------

Cada feature de Trello implementada, integrada y validada con tests exhaustivos.


🏢
### Workspaces (Espacios)

Agrupa tableros por área, proyecto o equipo con plan, miembros y permisos.

* ✓ Plan: gratis / equipo / empresa
* ✓ Miembros con roles
* ✓ Visibilidad pública opcional
* ✓ Color e icono personalizado

/api/v1/espacios · /espacios

🔐
### Permisos de tablero

Control de acceso granular con roles admin, editor y lector.

* ✓ 3 niveles: admin / editor / lector
* ✓ Notificaciones opt-in
* ✓ Invitación con rastreo
* ✓ Slug público para tableros públicos

/api/v1/tableros/{id}/permisos

👁
### Watch (Suscripciones)

Suscríbete a tickets, tableros o cualquier objeto. Sistema polimórfico.

* ✓ Toggle suscripción on/off
* ✓ Polimórfico (tipo + objeto\_id)
* ✓ Multi-canal: in\_app, email, web
* ✓ Auto-watch al ser asignado

/api/v1/watch

😀
### Reacciones con emojis

Reacciona a tickets y comentarios con emojis. Whitelist validada.

* ✓ Whitelist de 50+ emojis seguros
* ✓ Toggle on/off por usuario
* ✓ Conteo agregado por emoji
* ✓ XSS-safe (escape automático)

/api/v1/reacciones/toggle

🔔
### Centro de notificaciones

Notificaciones push de actividad con filtros por tipo y estado.

* ✓ 6 tipos: mencion, asignacion, watch, sla, butler, sistema
* ✓ Filtros: todas / no leidas / menciones / asignaciones
* ✓ Marcar individual o masivo
* ✓ Contador de no leídas en tiempo real

/notificaciones · /api/v1/notificaciones

🎨
### Campos personalizados

Extiende los tickets con campos a medida para tu equipo.

* ✓ 6 tipos: texto, número, dropdown, checkbox, fecha, url
* ✓ Por tablero, con posición drag&drop
* ✓ Requeridos / opcionales
* ✓ Colores personalizables

/api/v1/campos-personalizados

⚡
### Butler Automation

Reglas, botones y comandos programados para automatizar todo.

* ✓ Reglas por evento (X dispara Y)
* ✓ Botones de tarjeta / tablero
* ✓ Comandos cron con timezone
* ✓ Log de ejecuciones

/butler · /api/v1/botones

📊
### Vistas multidimensionales

Los mismos datos en 4 vistas: Tablero Kanban, Tabla, Calendario y Timeline.

* ✓ Tablero drag&drop
* ✓ Tabla con filtros y custom fields
* ✓ Calendario mensual por fechas
* ✓ Timeline estilo Gantt

/vistas/{tabla,calendario,timeline}

📝
### Markdown seguro

Editor Markdown con render XSS-safe y extracción de menciones.

* ✓ Parser propio XSS-safe
* ✓ @menciones automáticas
* ✓ Bloques de código y formato
* ✓ Links y listas

/api/v1/markdown/renderizar

📦
### Archivar / Restaurar NUEVO

Soft-delete profesional: archiva tarjetas sin perder historial y restáuralas cuando sea necesario.

* ✓ Botón ámbar con confirmación en el modal
* ✓ Auditoría completa (TICKET\_ARCHIVADO / DESARCHIVADO)
* ✓ Notificación Celery al archivar
* ✓ Vista "Archivados" en el Kanban

/api/v1/tickets/{id}/archivar · /desarchivar

Lo que hace posible todo esto


### 🛠 Backend

* ●**FastAPI** · Framework async con OpenAPI auto
* ●**SQLAlchemy 2.0** · ORM con relaciones polimórficas
* ●**Pydantic v2** · Validación + serialización
* ●**SQLite** · BD embebida para demo, compatible con PostgreSQL
* ●**JWT** · Auth Bearer + X-User-Id demo

### 🎨 Frontend

* ●**Jinja2** · Templates server-rendered
* ●**HTMX** · Interactividad sin escribir JS
* ●**TailwindCSS** · Utility-first CSS
* ●**SortableJS** · Drag&drop Kanban
* ●**Inter + JetBrains Mono** · Tipografía
