CONSULTA SQL PARA POBLAR LA TABLA PIVOTE:

```sql
SELECT
  modulo,
  SUM(CASE WHEN resultado_pruebas = 'N/A' THEN 1 ELSE 0 END) AS na,
  SUM(CASE WHEN resultado_pruebas = 'NOK' THEN 1 ELSE 0 END) AS nok,
  SUM(CASE WHEN resultado_pruebas = 'OK' THEN 1 ELSE 0 END) AS ok,
  SUM(CASE WHEN resultado_pruebas = 'OK CON OBS.' THEN 1 ELSE 0 END) AS ok_con_obs,
  SUM(CASE WHEN resultado_pruebas = 'POSTERGADA' THEN 1 ELSE 0 END) AS postergada,
  SUM(CASE WHEN resultado_pruebas IS NULL OR resultado_pruebas = '' THEN 1 ELSE 0 END) AS en_blanco,
  COUNT(*) AS total_general
FROM tickets
WHERE ambiente = 'QA'
GROUP BY modulo
ORDER BY modulo;
